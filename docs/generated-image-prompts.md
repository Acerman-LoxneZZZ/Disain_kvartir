## before

Use case: precise-object-edit. Asset type: an illustrative BEFORE image for a website before-after slider. Edit the supplied living-room photo into the very same room before renovation. Preserve EXACT camera position, lens, perspective, image framing and 4:3 aspect ratio; preserve wall corners, ceiling line, right-hand large window and outdoor view. Remove every furniture piece, rug, plant, mirror, artwork, lamp, accessories and skirting. Replace finished walls with plain unfinished grey plaster, floor with bare concrete. Leave an empty clean construction shell, believable daylight from the same window. No construction workers, debris, text, labels, watermark, split view or border. One full-frame photographic image matching the input architecture and camera for perfect before-after alignment.
