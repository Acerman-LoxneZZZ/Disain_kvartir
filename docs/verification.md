# Проверка страницы

Проверено 23 октября 2026 года.

- `npm run build`: TypeScript и production-сборка Vite проходят.
- `npm test`: 8 тестов формы проходят. Проверены валидные/невалидные данные, отсутствие endpoint без запроса, явный ответ `ok:true`, ошибки сети/HTTP/JSON, таймаут, недопустимый URL обработчика.
- После обновления инструмента оптимизации изображений npm сообщает 0 уязвимостей.
- Браузер: 360, 768, 1024 и 1440 px — горизонтального переполнения нет.
- Мобильное меню открывается и переводит к форме; FAQ раскрывается.
- Фильтр «Дома» оставляет один проект; «Все проекты» возвращает все карточки.
- Диалог проекта открывается, переключает изображения кнопками и стрелками, закрывается по Escape, возвращает фокус на исходную карточку.
- Range реагирует на End, Home и ArrowRight; `aria-valuetext` обновляется вместе с разделителем.
- Пустая форма показывает три сообщения и переводит фокус к первому полю. Заполненная форма без endpoint сообщает, что данные не отправлены.
- Повреждённых загруженных изображений в браузере не обнаружено.
- CSS для `prefers-reduced-motion` проверен по исходному коду: анимации и переходы выключаются, содержимое видно. Физический сенсорный экран не использовался; касания поддерживаются нативным HTML range.
- `dist/index.html` содержит русские SEO/OG-метаданные; демонстрационный `robots.txt` запрещает индексацию. При `demo:false` и заданном `seo.url` build-плагин создаёт публичный sitemap и canonical.
- Детектор Impeccable на `src`: `[]` (механических замечаний нет).
- Независимая проверка по скриншотам и исходникам: `ship` после двух исправлений. Усилен контраст белой подписи на первом экране; подтверждены пороги 3:1 на широком и 4.5:1 на узком экране с подписью 22px. Убрана надпись над заголовком проекта, пояснение о демонстрационном кейсе сохранено. Финальный проход оценивал именно эти два исправления, оба закрыты.
- Полные снимки и превью согласованы; превью — верхние фрагменты полных снимков, как указано в `.impeccable/review/capture-notes.md`.

Скриншоты полной страницы: `.impeccable/review/desktop.png`, `.impeccable/review/mobile.png`. Демонстрационные данные формы после проверки сброшены.
