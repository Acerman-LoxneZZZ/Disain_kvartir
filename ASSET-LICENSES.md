# Изображения и шрифты

## Фотографии интерьеров

Использованы бесплатные фотографии с CDN Unsplash, не Unsplash+. Источники для каждого файла записаны в `docs/image-provenance.json`.

Лицензия: https://unsplash.com/license — разрешает загрузку и коммерческое использование фотографий. Фото не выдаются за реальные работы демонстрационного дизайнера. При замене материалов используйте фотографии, права на которые у вас есть, и согласуйте публикацию с правообладателями.

`comparison-1600.webp` — та же фотография, что `project-light-1600.webp`; это исходный кадр для создания демонстрационного состояния до отделки.

## Сгенерированные материалы

- `before-*.webp` — ИИ-иллюстрация состояния комнаты без отделки на основе фотографии `photo-1600210492486-724fe5c67fb0`.
- `portrait-*.webp` — ИИ-портрет вымышленного человека, не основанный на конкретной личности.

Созданы встроенным imagegen для этого проекта. Точные промпты сохранены в `docs/generated-image-prompts.md`. На странице есть подписи, позволяющие отличить эти изображения от реальных материалов дизайнера.
